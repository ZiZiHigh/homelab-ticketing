HOMELAB-TICKETING CHANGELOG
===========================

What this file is: chronological log of the osTicket deployment on the
homelab Arch server. Last updated: 2026-10-21. Each block lists the step,
what changed, why, the evidence and how to undo it. Failures stay in.

Format: [YYYY-MM-DD HH:MM] short title
        What / Why / How / Validate / Undo / Note

Entries are added after every step. The detailed version of a hard step is in
journal/NN-short-name.txt. No secrets, passwords or tokens belong here.

Correction note (2026-10-21 14:25): The 13:55 and 14:08 entries below
misidentified the Access denied cause. The latest entry at the end of this
file has the corrected root cause: the user was on the client sign-in form,
not the agent form. Read that entry first. The old entries are kept because
this is a chronological log.
